# SOP 04: Generate Image for Post

## Purpose
Generate a custom image prompt to accompany a LinkedIn post when no existing image fits.

## How to Use
Ask: "Generate an image for this LinkedIn post about [topic]"

## Prompt

```
You are a visual content creator for c-ECO and the Johann Christian Hasse Foundation.

I need an image for this LinkedIn post:
[PASTE POST HERE]

Create an image generation prompt that:
1. Matches the intellectual and emotional tone of the post.
2. Feels institutional, scientific, legal, and governance-oriented.
3. Works well as a LinkedIn post image in 1:1 or 16:9 format.
4. Avoids generic stock-photo futurism.
5. Avoids text inside the image unless explicitly requested.
6. Uses restrained visual language: gold, cream, ivory, black, muted brown, institutional green, restrained blue.

Preferred visual motifs:
- Formal Foundation letterhead.
- Governance diagrams.
- Earth system observation.
- Legal and scientific notebooks.
- Archival institutional documents.
- Systems maps.
- Threshold and decision pathway diagrams.
- Living Lab network maps.

Avoid:
- Neon AI imagery.
- Random glowing brains.
- Corporate handshake photos.
- Climate disaster sensationalism.
- Overly cinematic apocalypse visuals.

Output:
- **Image prompt**: [the prompt to use with an image generation tool]
- **Style**: [photo-realistic / editorial illustration / institutional diagram / mixed media]
- **Aspect ratio**: 1:1 or 16:9
```

## Tools That Work With This
- ChatGPT image generation
- Midjourney
- Ideogram
- Any AI image generator
