# SOP 07: Analyze Past Post Performance

## Purpose
Review recent LinkedIn posts to understand what is building credibility, attracting aligned people, and improving clarity.

## How to Use
Ask: "Analyze my recent LinkedIn post performance"

## Prompt

```
You are a LinkedIn analytics strategist for c-ECO and the Johann Christian Hasse Foundation.

Read these files for context:
- 1/strategy.md (current strategy)
- 2/brand-guidelines.md (voice and positioning)
- 4/past-posts/ (past post examples, if available)

I'm going to share recent LinkedIn post performance data. Analyze it and tell me:

1. **Top Performers**: Which posts earned the most meaningful engagement?
2. **Credibility Signals**: Which posts attracted serious comments, saves, profile visits, or relevant conversations?
3. **Weak Posts**: Which posts sounded too vague, too dense, too promotional, or too abstract?
4. **Hook Analysis**: Which openings worked best and why?
5. **Audience Fit**: Which posts best reached scientists, lawyers, funders, advisors, governance experts, or institutional partners?
6. **CTA Effectiveness**: Which invitations created meaningful next steps?
7. **Recommendations**: 3-5 specific changes for next week.

Be candid, precise, and practical.

DATA:
[PASTE YOUR LINKEDIN ANALYTICS DATA HERE]
```

## How to Collect Data
1. Go to your LinkedIn profile.
2. Open Analytics or view each post's stats.
3. For each post from the last 2-4 weeks, note:
   - Post topic / hook
   - Impressions
   - Engagement
   - Comments quality
   - Saves
   - Reposts
   - Profile visits
   - Website clicks
   - Relevant inbound messages

## Tracking Template
Save your data in `4/past-posts/` using this format:

```
## [Date] - [Post Topic]
- Hook: [First line of the post]
- Type: [Founder Reflection / Governance Insight / Scientific Governance Explainer / Legal Architecture / Build in Public / Funding and Institution Building / Partnership Invitation]
- Impressions: [number]
- Likes: [number]
- Comments: [number]
- Reposts: [number]
- Saves: [number]
- Website clicks: [number]
- Relevant inbound messages: [number]
- Notes: [what worked or did not work]
```
