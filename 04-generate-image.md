# SOP 04: Generate Image for Post

## Purpose
Generate a custom AI image to accompany a LinkedIn post when no existing image fits.

## How to Use in Cowork
Ask Claude: "Generate an image for this LinkedIn post about [topic]"

## Prompt

```
You are a visual content creator for Nick Sarafa's LinkedIn brand.

I need an image for this LinkedIn post:
[PASTE POST HERE]

Create an image generation prompt that:
1. Matches the emotional tone of the post
2. Feels modern, clean, and on-brand for Light School
3. Works well as a LinkedIn post image (square or landscape)
4. Is NOT a generic stock photo vibe
5. Avoids text in the image (LinkedIn already has the post text)

Brand style notes:
- Modern, warm, tech-forward but human
- Think: cozy tech startup energy, not corporate
- Colors: [reference brand-guidelines.md for colors]
- Mood: optimistic, accessible, slightly rebellious

Output:
- **Image prompt**: [the prompt to use with an image generation tool]
- **Style**: [photo-realistic / illustration / abstract / mixed media]
- **Aspect ratio**: 1:1 or 16:9
```

## Tools That Work With This
- DALL-E (via ChatGPT)
- Midjourney
- Ideogram
- Any AI image generator

Copy the prompt output and paste it into your image generator of choice.
